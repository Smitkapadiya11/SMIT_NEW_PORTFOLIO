# Smit Kapadiya — AI Portfolio

Premium 3D portfolio website for **Smit Kapadiya**, AI Generalist & Automation Specialist.

**Live:** [smit-new-portfolio.vercel.app](https://smit-new-portfolio.vercel.app)

## Stack

- Next.js 14 · TypeScript · Tailwind CSS
- React Three Fiber · Three.js (3D hero & showcase)
- Framer Motion · anime.js · Lenis smooth scroll

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm start
```

## Environment Variables

Copy `.env.local.example` to `.env.local`:

```
NEXT_PUBLIC_EMAILJS_SERVICE_ID=
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=
```

## Screenshots

```bash
npm run screenshots
```

Generates project screenshots in `public/screenshots/`.
